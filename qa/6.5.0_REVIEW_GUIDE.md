# 6.5.0 Independent QA Review Guide

Reference baseline: EMS SaaS main commit `cb15919032596021e732321a4c7c84e60429f5f6`.

## Mandatory software checks
- `backend/main.py` contains no CREATE/ALTER/DROP DDL.
- `python -m alembic -c backend/alembic.ini check` and `upgrade head` succeed against a disposable PostgreSQL database.
- Fresh database reaches Alembic head.
- Existing v5/v6 database reaches the same head without destructive table deletion.
- Legacy STATE_VERSION=4 Pi JSON loads when new usage/reset fields are absent.
- Legacy SQLite queue migrates before indexes are created.
- Command FSM rejects illegal transitions and enforces 120s delivery lease / 300s absolute expiry.
- Browser auth has no access JWT in localStorage/sessionStorage.
- Auth cookies are HttpOnly/Secure in production; CSRF is required for unsafe authenticated browser requests.
- Retired devices cannot be reassigned.
- Firmware download authenticates the device identity and key together.

## Mandatory physical/release gates
- HIL fault-injection matrix on production GPIO/relay/feedback hardware.
- Storage endurance soak with measured application bytes, filesystem/block writes, physical writes and system WAF.
- Signed OTA and A/B rollback qualification before enabling production OTA.
